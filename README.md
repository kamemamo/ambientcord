# そよぎ（仮）

環境と絵の関係を書く、日本語の小さな言語です。「アンビエント・コーディング」の試作です。

**試す：** https://kamemamo.github.io/ambientcord/

```
空     ← 時刻
線の色 ← 気温   青 … 橙
速さ   ← 音量
軌跡   ← 照度   反転
向き   ← 風
方角   ← 風向
渦     ← 気配   近く 22
```

- 一行に一つ、`表現 ← 環境` と書きます。書き換えるとその場で絵が変わります。
- 気温・風・風向・雨・雲・湿度は、[Open-Meteo](https://open-meteo.com/) の気象データにつながります（都市名か現在地を指定）。
- 音量は「マイクをつなぐ」でその場の実際の音になります（大きさを測るだけで、録音も送信もしません）。照度は「明るさをつなぐ」で照度センサーか、なければカメラ映像の平均の明るさになります（明るさを測るだけで、表示・録画・送信はしません）。

ファイルは `index.html` 一つだけで、ほかに必要なものはありません。
