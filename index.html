そよぎ（仮）環境と絵の関係を書く言語

「何が何に従うか」を一行ずつ書くと、絵がその場で変わります。命令ではなく関係だけを書くので、書き終えたあとも環境が絵を動かし続けます。

    書き方
    
    
      
      
    1. 一行に一つ、表現 ← 環境 と書きます。<- や は でもかまいません。
      2. 
      
    2. 環境どうしは と でつなぐと平均になります。数値（0〜1）もそのまま書けます。
      3. 
      
    3. 右に言葉を足すと値が変わります。反転・× 0.5・+ 0.2・段階 4・ゆっくり、線の色には 青 … 橙 のような色のつながり、渦には 近く 30。
      4. 
    
    
    
    すべての値は 0 から 1 の間に揃えてから表現に渡します。# から後ろはメモとして読み飛ばします。
    
    
    実際の天気について
    
    
    気温・風・風向・雨・雲・湿度は、Open-Meteo の気象データにつなぐと実際の値になります（10分ごとに更新）。claude.ai の中で開いているときは外への通信が止められているので、シミュレーションの値で動きます。このHTMLファイルを自分のブラウザや Raspberry Pi の画面で開くと、そのまま実際の天気に反応します。照度は、今後センサーにつなぐ予定です。
    
    
    マイクについて
    
    
    「マイクをつなぐ」を押すと、音量 がその場の実際の音の大きさになります。測るのは大きさだけで、録音も送信もしません。静かな部屋で 35 dB 前後、話し声で 60 dB 前後になるよう合わせてあり、場所によって合わないときは 感度 で上下させます。ブラウザの決まりで、https か localhost、または自分のパソコンのファイルとして開いたときに使えます。
    
    
    風向は「風が吹いてくる方角」で、北が 0、東が 0.25、南が 0.5、西が 0.75 です。方角 ← 風向 と書くと、線は風下へ流れます。
